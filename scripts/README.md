# Scripts

Script entrypoints:

- `prove-risc0-groth16.sh` - run the RISC Zero Groth16 host prover from a Linux shell with the RISC Zero toolchain.
- `deploy-real-zk-testnet.sh` - build and deploy the Groth16 verifier plus a gatekeeper wired to it.

The app can already be run with `npm run dev:api` and `npm run dev:web`.
