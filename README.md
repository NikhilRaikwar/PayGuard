# PayGuard

ZK-enforced AI agent payment policy layer on Stellar.

PayGuard is an early-stage project for building private, programmable controls around AI-initiated payments. The goal is to let users define payment policies off-chain, commit only a policy hash on Stellar, and require zero-knowledge proof verification before an agent payment can execute.

This repository is currently initialized with the project overview and license. Implementation will be added in future commits.
